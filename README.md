# Konvoi

Gruppen-Fahrt-App im Browser: Freunde sehen sich live auf der Karte, mit Tempo und Abstand.
Mit einem Tipp markiert man für alle die nächste Tankstelle, Pause oder Essen, oder meldet „Wartet“ oder „Panne“.

- Karte: Leaflet + OpenStreetMap/CARTO
- Live-Gruppe: Supabase Realtime (Broadcast + Presence)
- Orte: OpenStreetMap Overpass API

## Einrichten
In `index.html` oben `SUPABASE_URL` und `SUPABASE_KEY` (Publishable Key) eintragen.
